# Figurinhas automáticas da Sakura-MD

| Arquivo | Comportamento |
|---|---|
| `legacy/bomdia.webp` | `bom dia` / `bum dia`; enviado junto com `bomdia.mp3` |
| `legacy/boatarde.webp` | `boa tarde`; enviado junto com `boatarde.mp3` |
| `legacy/boanoite.webp` | `boa noite`; enviado junto com `boanoite.mp3` |
| `legacy/risada.webp` | kkk, ksks, kakaka, haha, rsrs, rachei e variações; nunca envia áudio |
| `legacy/ban.webp` | exclusivo de `.ban`; enviado junto com `ban.mp3` |
| `legacy/palavrao.webp` | palavrões e ofensas comuns |
| `legacy/treta.webp` | palavras como treta/briga ou conflito contextual entre duas pessoas |
| `legacy/elogiosakura.webp` | elogios que mencionam Sakura |
| `legacy/calabocasakura.webp` | frases pedindo para a Sakura ficar quieta |
| `legacy/oie.webp` | saudações curtas e exatas |
| `legacy/banho.webp` | banho / vou tomar banho |
| `legacy/presente.webp` | presente / Natal |
| `legacy/sim.webp` | respostas curtas de confirmação |
| `legacy/sono.webp` | sono / vou dormir |
| `legacy/tedio.webp` | tédio / estou entediado(a) |

As frases e regras ficam em `data/triggers.js`. O painel `.automaticos` gerencia o estado sem apagar os arquivos.


## Metadados

As figurinhas automáticas oficiais usam `sakura-md ❅ drux domina` como pacote e publicador.
